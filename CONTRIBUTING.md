# Contributing

Brand icons live in `custom_components/xthings_lock/brand/` (Home Assistant 2026.3+). Do not PR [home-assistant/brands](https://github.com/home-assistant/brands) for this custom integration.

HACS default-store inclusion is a PR against [hacs/default](https://github.com/hacs/default) (`integration` list, alphabetically). Requirements: public GitHub repo, hassfest + HACS Action green with **no** `ignore`, then a GitHub release.
